# PsicoLive Frontend

Frontend da aplicação **PsicoLive**, desenvolvido em **React + TypeScript** com **Vite**.  
Este projeto consome a API do backend (ASP.NET Core + Identity) para autenticação, gerenciamento de usuários e sessões.

---

## 🚀 Tecnologias utilizadas
- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/) (build e dev server)
- [Axios](https://axios-http.com/) (requisições HTTP)
- [React Router](https://reactrouter.com/) (navegação)
- [Material UI](https://mui.com/) (componentes visuais)

---

## 📦 Instalação

### Pré-requisitos
- Node.js (>= 18.x recomendado, você está com 24.x 👍)
- npm (>= 9.x)

### Passos
```bash
# Clone o repositório
git clone https://github.com/<seu-usuario>/psicolive-frontend.git

# Acesse a pasta
cd psicolive-frontend

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
